# Commander's vision.

## Accelerate Claude Code
Agentic engineering inside a flight themed directory. Saturate Claude's harness tools with curated content. keep context fresh for agents. 

## Roleplay
Let's make this fun. flight themed. Military ranks set the tone for roles given their influence in the project.

## Themed HTML page suite
Interactive interface. Prompt builder and other ai tools. Agents show visualisations to the human. The human returns content back to the agent.

## Workshops
Discrete units of work contained inside individual directories. Agent output, reports, plans, state, decisions, truth, logs, verification. Branch isolated. Promote important stuff to global tools (eg decisions to claude.md). Retry work at anytime. guide agents with "truth" where the work happens. build and update requirements over time to retry the work.

## launches
Multi agent workflows of all shapes, claude picks intelligently to build from the  workshop. Scoped and specced work, checkable, reviewed, PR'd, worktrees, dynamic workflows. 

## local CLI
Agents can manipulate and read the flightdeck with a local CLI. start web servers, bulk commit the flightdeck, and any other suitable actions (to be discovered).

## dev-workspace
dev-workspace was built for the first era of the agentic age. A place for a Human in the loop and a single agent to collaborate. Flightdeck is for the next era, agentic engineering. HITL is not forgotten, Agentic workflows first class citizens.
Humans altitude is raised.

## Cheap tokens, smart agents.
Effective use of Claude 20X max subscription. Agents have come of age. Each tier utilised for their purposes. frontier agents are too expensive to build and explore, but smart enough to guide, dispatch, check and improve the project and other lesser agents. smaller tier agents have become highly efficient and intelligent enough for distinct purposes. Opus, sonnet, haiku all usable for agentic invocations.

## Built with quality
Each sub-system isolated, testable, improvable in isolation from other sub-systems. testbenches, laboratories, teams purpose built to improve the flightdeck.

## Human energy.
Humans energy is limited, their focus finite, they fatigue.  flightdeck leans on agent recognisable "truth" devices to relieve the human from making bulk decisions and course correcting. heavy focus on transfering human truth into improvable documents like; rubrics, policies, schemas, templates, examples, manuals, library. Human wants high impact but long lasting inputs.

## Keep it simple
Sometimes the human just wants to jump into a chat window and do regular HITL with a single agent, like the good ol days. Flightdeck doesn't constrain the human to advanced usage only.

## Manuals and libraries
Operator, technical and maintenance manuals created adjacent to the work and stored globally. Library for concepts, knowledge and best practices. kept fresh and updated. mid tier agents preside over the corpus, reviewing work against it, delivering it where it needs to go. 

## Laboratory 
A lab for evaluating and drilling flightdeck. drills are test runs that look to discover and fine tune hidden functionality (particulary with teams), revealing best practices etc. evaluations are the standard evals with fixtures etc that can be used to hillclimb docuements. Flightdeck infrastructure is designed to be easily evaluated, drilled and improved.
