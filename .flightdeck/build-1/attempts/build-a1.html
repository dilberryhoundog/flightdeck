Things you should know

  • All seven together. I merged every branch into one scratch copy and ran everything: all tests, both plugin checks, the hard rules, the drills. All green, and each pull request can be removed with the rest still green.
  • One scare, no damage. A review agent pointed the git remote of my checkout at a throwaway local repository (it made a git worktree, which shares settings with the main checkout, instead of a separate copy). For a few minutes some pushes went there instead of GitHub. GitHub was never touched; I restored the remote and pushed what was missing. The rule against it is now in the build script and in build-1's lessons.
  • Report files. Claude Code does not let a subagent write files called report or findings, so I wrote each pull request's report and findings from the stage records.
  • Scored test cases. Claude Code only reads them from inside the plugin, so they live in flightdeck/evals/ (the plan's own fallback). PR 6's two cases scored 1.00. PR 3's and PR 7's load but scored 0 in about 15 seconds, which is captured to look at. Two cases need a sandbox this machine does not have.
  • Captured work. The agents captured 23 follow-ups in .flightdeck/workshops.md (on PR 1's branch) under their own heading, each one plain sentence; with the made-up demo task, the card shows 24 waiting to start. They are waiting for you to activate, fold into other work, or delete. The build's lessons for next time are in build-1's context.md.
  • Usage. Building took about 13.4 million subagent tokens across about 103 agents (planning took about 7.4 million more). Nothing ran above Opus at high effort.
