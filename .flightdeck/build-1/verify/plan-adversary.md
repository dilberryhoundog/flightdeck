Findings are sorted by severity, then confidence. S = severity (H/M/L), C = confidence (H/M/L).

Its CONTEXT block carries "the model ceiling", and PR 1's source-adaptation text says "Every `model: fable` becomes `opus`", so `build.js` is likely to contain the word too and be denied as well. EVIDENCE: plan.md section 3.8 "Ceiling rule"; section 2(c); constraints.md line 8; plan.js line 75. Trigger: install PR 1 with the two commands in section 4, then ask Claude to rerun `plan.js` with the Workflow tool, and the guard denies it. Alternatively, exempt `.flightdeck/*/workflows/`. Add a hook test that runs the real `plan.js` through the guard and expects it to be allowed.
