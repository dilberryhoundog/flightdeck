# Extracts

A placeholder for extractions: bulk sources condensed into key findings and distributed into self-sustaining content. Having somewhere to extract to relieves the pressure to keep bulk long term, because a large log folder can be mined into its findings later.

- `topics/` — the commander's statements mined from session transcripts and written advice, filed against timeless flightdeck system topics. One file per topic under `MANIFEST-topics.json`. This is the starter, and the only extraction that exists today.

Future work. M001 scaffolds the room; what else is extracted, and when, is not yet decided.
