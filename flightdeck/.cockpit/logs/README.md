# Logs

Log-style assets: things appended as they happen and read back by date or topic. One session log per pilot session, and beside it the other logs the cockpit keeps: the git terrain, the commander's topics, the frozen crew archive.

## Session logs

One file per session, `YYYY-MM-DD_<session>.md`, where `<session>` is the first eight characters of the Claude Code session id. A pilot may fly more than once a day; the session id keeps each flight's log separate and lets the log be matched to its transcript. Entries appended in order, each with a mission id. `MANIFEST-logs.json` lists every log with its date, session id and a one-line summary so a future pilot can find a flight without opening it.

Entry shape: `## short title — M###`, then at most two lines: what changed, what is next. One entry per team run, not per message. Facts, not narrative; the team file and the dossier carry the detail. Add this session's entry to `MANIFEST-logs.json` at session start with a placeholder summary, and finish the summary at session end, so a crashed session is still indexed.

## Crew manifest

`crew-manifest.json` is frozen at C001 to C011, the dispatches that predate `../dispatch/`; teams and their seats are recorded there now. It recorded every crew dispatch, subagent or teammate: type, model, mode, purpose, access, delivery, outcome, the pilot's verification of the report, where it was filed and cost. Field meanings are in the file. Entries are added at spawn and completed on return. Over time it shows which crew shapes work; a shape that recurs and performs is recruited into `quarters/crew/` with a dossier.

Finding the session id: the SessionStart hook payload carries `session_id`, and `claude agents --json` lists it for running sessions. The hook prints it into the opening context as `[cockpit] session=...`.

## Other logs

- `topics/` — the commander's statements filed against timeless flightdeck system topics, `MANIFEST-topics.json` plus one file per topic. See `topics/README.md`.
- `MANIFEST-branches.json` — the git terrain: only what git cannot tell (role, parent, merged higher, pending decision); tips and lag are regenerated by `../base/bin/branch-terrain.sh`.
- `crew-manifest.json` — frozen archive of dispatches C001 to C011 before `../dispatch/` existed.
