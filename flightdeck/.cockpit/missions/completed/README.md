# Completed Missions

A mission moves here when the commander closes it. The file keeps its id and name. Before the move the pilot writes the outcome, the trophies (wins), the battle scars (losses and mistakes) and the re-activation condition. `missions.json` keeps the entry with status `complete` and the new file path; a re-activated mission moves back with a new dated `Re-activated` line under its header and its status set again to `in_progress`. The commander's rule (2026-09-18): transfer the mission after it completes, celebrate the trophies, note the battle scars, and enable re-activation if required.
