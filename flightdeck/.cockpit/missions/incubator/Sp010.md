# Sp010 — A CLAUDE.md excellence team

A team that holds every line of the cockpit `CLAUDE.md` to stated tests and moves what fails them. The commander's two tests for a line: would anything change if it were removed, and does every session need it. A run of lines on one subject that only some sessions need is a manual, leaving at most a one-line pointer. The commander's shape for thinking a rule through before compressing it: problem, solution, risk.

Material the team would start from: the harness loads a folder's CLAUDE.md only when something in that folder is read, while an `@` import loads at launch (`notepad/ideas-2026-09-20/scout.md`), so a per-room CLAUDE.md is where room conventions can move; rule 2 is the longest line in the file and is a candidate; rule numbers are cited across the cockpit, so renumbering waits for the reference checker.
