# docs-verifier: verification of runs-recon — M001

Crew report, C015 job 2 batch 2, received 2026-09-18. Pilot's note: the four "unsupported" verdicts on claims 3, 11, 13 and 15 are claims flightcrew's own runlog and hooks README make from experience in runs, not from docs; unsupported means the docs are silent, not that the observation was false. They matter to the budget and workflow missions and should be tested directly before a mission leans on them. Claim 12's correction (default worktree base is the remote default branch, not HEAD) is a real finding for any launch that dispatches worktree workers from an unpushed branch.

1. Twelve hook events bound (14 actually listed: SessionStart...Stop). Verdict: confirmed as valid names, but count is wrong — the list has 14 entries, not 12. All 14 are documented events. URL: https://code.claude.com/docs/en/hooks.
2. PreToolUse blocks via JSON on exit 0; PostToolUse/Stop block via exit 2. Verdict: contradicted (incomplete). Docs show PreToolUse can ALSO block via exit 2: table states "PreToolUse | Yes | Blocks the tool call." JSON `hookSpecificOutput.permissionDecision` is one path, not the only one. Source: https://code.claude.com/docs/en/hooks, exit-code-2-behavior-per-event table.
3. Strictest of two conflicting PreToolUse hooks wins. Verdict: unsupported. Docs state hooks "run in parallel" but give no conflict-resolution rule for contradictory decisions. Source: https://code.claude.com/docs/en/hooks.
4. Claude Code ends the turn after eight consecutive Stop-hook blocks. Verdict: confirmed verbatim. Source: https://code.claude.com/docs/en/best-practices — "Claude Code overrides the hook and ends the turn after 8 consecutive blocks."
5. WorktreeCreate hook replaces creation, must print the directory, nonzero exit aborts. Verdict: confirmed. Source: https://code.claude.com/docs/en/hooks — "any non-zero exit code from WorktreeCreate aborts worktree creation"; https://code.claude.com/docs/en/worktrees example hook "prints the directory path so Claude Code can use it as the session's working directory."
6. $CLAUDE_PROJECT_DIR resolves from wherever the session starts, worktrees included. Verdict: confirmed verbatim. Source: https://code.claude.com/docs/en/hooks / worktrees — "it still points at the project root where the session started."
7. Minimal PATH excludes version-manager shims. Verdict: unsupported. No PATH-composition text found in current hooks docs; only environment inheritance (OTEL scrubbing) is documented. Source: https://code.claude.com/docs/en/hooks.
8. Hooks in `.claude/settings.json` require workspace trust; `-p` skips it unless `--bare`. Verdict: confirmed. Source: https://code.claude.com/docs/en/worktrees — "Interactive runs require workspace trust... Non-interactive runs with -p skip the trust check"; consistent with project subagent/skill trust rules on the same page.
9. `worktree.baseRef` must be `head` or subagents branch from remote default. Verdict: confirmed verbatim. Source: https://code.claude.com/docs/en/worktrees — "Subagent worktrees use the same base branch as --worktree, so they branch from your repository's default branch unless worktree.baseRef is set to 'head'."
10. Workflow invoked as `/<name>` with `args` as structured data; `Date.now()`, `new Date()`, `Math.random()` unavailable. Verdict: confirmed. Source: https://code.claude.com/docs/en/workflows — "Claude Code makes Date.now(), Math.random(), and a no-argument new Date() throw inside the script"; "Claude passes the list as structured data."
11. Workflow runtime rejects a script ending with `export default`. Verdict: unsupported. Docs only require `export const meta` as the first statement; no mention of rejecting `export default` anywhere. Source: https://code.claude.com/docs/en/workflows.
12. Subagent worktree branches from HEAD by default; uncommitted launch-folder file invisible to worker. Verdict: contradicted on the default. Docs: default base is `"fresh"` (repository's remote default branch), not local HEAD — "unless worktree.baseRef is set to 'head'." The invisibility half is true but for a different reason (a worktree checks out a commit, never uncommitted changes), independent of baseRef. Source: https://code.claude.com/docs/en/worktrees.
13. A stopped agent cannot be resumed. Verdict: unsupported. Docs confirm Explore/Plan specifically can't be resumed ("one-shot and return no agent ID"), implying other subagents normally can be; no general statement found about agents stopped mid-run. Source: https://code.claude.com/docs/en/sub-agents.
14. Only frontmatter `maxTurns` actually limits an agent. Verdict: confirmed. `maxTurns` is the only documented turn-limiting subagent field ("agent stops and returns partial output" at the limit); no alternate official turn-limit field exists. Source: https://code.claude.com/docs/en/sub-agents.
15. A stall message on exit 0 is not displayed by Claude Code. Verdict: unsupported. Docs show the opposite for `/goal`'s own stall detection ("Claude Code stops the loop, prints a warning"), and `systemMessage` on exit 0 is shown "on every event except SessionEnd and PostCompact." No text confirms a Stop-hook-authored stall message on exit 0 is suppressed. Source: https://code.claude.com/docs/en/goal, https://code.claude.com/docs/en/hooks.
16. Permissions allowlist supports `Agent(<role>)` and `Workflow(<name>)` forms. Verdict: confirmed. Source: https://code.claude.com/docs/en/permissions — "`Agent(my-custom-agent)` matches a custom subagent named `my-custom-agent`"; https://code.claude.com/docs/en/workflows — "`Workflow(<name>)` approves one saved workflow by name."
17. `sandbox.filesystem.deny` covers Bash and children; `permissions.deny` on file tools does not. Verdict: confirmed. Source: https://code.claude.com/docs/en/sandboxing — filesystem rules are "enforced at the OS level, so all commands running inside the sandbox, including their child processes, respect them"; separately, "Bash commands that modify files within the sandbox boundaries execute without prompting, even in Manual mode, where the file edit tools would prompt" — demonstrating the two mechanisms are independent and don't cover each other.

All dates checked: 2026-09-18.
