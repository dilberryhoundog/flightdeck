# assets-scout

Inventory what already exists on other branches for a stated need, and judge how reusable each asset is, so the team does not design what flightcrew has already built.

## How to dispatch

Sonnet. Read-only git only (`ls-tree`, `show`, `grep`, `log`, diff stat); never check out or write. Name the branches to cover and the ones to ignore. Give the recon leads as leads to verify, not facts. Ask per asset for a reuse verdict (as is, with extraction, pattern only) and the single best starting branch and path. 200 lines; scratchpad file plus summary to the pilot and the paper's holder.
