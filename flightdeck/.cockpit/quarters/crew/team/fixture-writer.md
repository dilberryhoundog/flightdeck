# fixture-writer

Write the fixture tree and the table test for a tool from its accepted plan, never from its code, so the test is an independent statement of what the tool must do.

## How to dispatch

Sonnet. Give it the spec, the accepted plan and the case list, and a write boundary limited to the test file and the fixture folder. Tell it not to read the builder's code until its test is written. It reports each case in one line with what it proves.
