# tool-builder

Build cockpit tooling from a written spec: plan first, then code in the style of `base/bin/`, to green against a test someone else wrote.

## How to dispatch

Opus. Give it the spec file, the design documents behind it and a write boundary stated as paths. Python 3 standard library, compatible with the system interpreter. The plan is its first deliverable and is attacked before it builds. It may question the seat that holds the design. It reports what it ran and what the output was.
