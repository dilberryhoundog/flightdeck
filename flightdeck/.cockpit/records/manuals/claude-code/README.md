# Claude Code Records

Facts about the harness from official docs. Each file names its `Source:` URLs, research date and CLI version. Re-research when the CLI version moves; the harness changes quickly.

- `agent-teams.md` — lead session plus teammates with a shared mailbox and task list. Experimental.
- `agent-team-function.md` — what the cockpit has measured about teams: lifetime, what a teammate is given, capability fixed at spawn, permissions, the task list and its race, hooks, messages and state, the human at a seat (stub, T015 to T017).
- `session-messaging.md` — ListAgents and SendMessage between sessions, local and remote.
- `settings-and-launch.md` — settings files, launch flags, agent definitions, resume behaviour.
- `subagents.md` — the Agent tool: fresh vs fork, worktree isolation, agent definitions.
- `harness-register.md` — register: claims flightcrew's code and manuals make about Claude Code, each confirmed or contradicted with URL and date; consulted in disputes.

Last researched: 2026-09-17, CLI 2.1.274.
