# XX-002 — A commander response is extracted, and is never extracted

Both sides are sentences inside the same record, CA-008, extracted from `cockpit.constitution` line 32, which sets what happens to a commander response written inside a pilot record.

## CA-008 (32.1)

"If written internally they stay frozen inside the document as the commander wrote them, but also immediately extracted into the adjacent commander record corpus, by an agent who rewrites them in the language and format required." [32]

## CA-008 (32.4)

"The CR is never extracted elsewhere only the contained, orders, advice, questions are extracted." [32]

## The contradiction

The first sentence says the response itself is immediately extracted into the commander record corpus and rewritten there, which would put a CR file in `records/commander/responses/`. The fourth sentence of the same paragraph says the response is never extracted and that only the orders, advice and questions inside it are. A reading that saves both is possible, that "extracted" in the first sentence loosely means the contents are extracted while the response stays put, but the first sentence says the response is extracted "into the adjacent commander record corpus" and rewritten "in the language and format required", which describes a record being made of the response itself. CA-008 contradicts itself. The two readings lead to different files on disk, so the pilot cannot choose between them without guessing.
