## Task: agent
The product is itself agent-shaped: prompts, agent definitions, tools or workflows whose output varies between runs. The spec tags every behaviour with the class its check belongs to, and the class is carried on the check entry in the pinned tests map; a unit inherits it through the check ids it names. Cut one unit per tagged behaviour, each unit holding checks of a single class, so a varying unit's evidence is never mixed with a deterministic one's. Wave 0 is the single `kind: contracts` unit and delivers the harness the varying classes are measured through — the generator entry point, the fixed sample and the rubric file — with its contract checks green before any statistical or judged unit starts.
Read the pinned tests map at step 1 and confirm each check of these classes carries what its class owes; a check that does not is a spec silence and goes to `fc launch escalate spec-gap --detail "…"` before the plan is written. The four classes and what each owes: `[deterministic]` — an exact check, run once, pass or fail. `[property]` — an invariant that must hold over every generated case, with the generator and its seed pinned in the check. `[statistical]` — a rate over a fixed sample, with the sample, the threshold and the tolerance stated before the run and the observed rate recorded in the evidence. `[judged]` — a rubric a human applies, reading it at gate 3 beside the ledger and the unverified lines, with the verdict appended by `fc events append <json> --stated`.
Build the deterministic units first: they hold the shape the varying ones are measured inside. A statistical or judged behaviour that reaches plan time with no threshold or rubric written down is not the plan's to record: run `fc launch escalate spec-gap --detail "…"` naming the behaviour, because only a human can enter it in the tests map's unverified list with a reason. The report's unverified line then carries it to gate 3.
Risks worth naming: a threshold chosen after seeing the result, a sample too small to separate the classes, and a judged behaviour whose rubric drifts between passes.
