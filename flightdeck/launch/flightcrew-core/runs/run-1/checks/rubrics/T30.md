# Rubric · T30 · the orchestrator hands the human back a reading

**Covers** B24.

**Subject** this run's orchestrator session: the transcript recorded in `flightdeck/launch/flightcrew-core/runs/run-1/events.jsonl`, read beside `runs/run-1/liftoff/<name>.json` and whatever each workflow wrote. Read only the orchestrator's own turns; a subagent's transcript is not the subject.

**How to read** Find every turn where a workflow returned, and read the orchestrator's next message to the human. There are as many of these as the liftoff's sequence has entries. Answer for the set: an answer is `no` the moment one such message fails it, and the quote is that message.

**Questions**

1. After each workflow returned, did the orchestrator report that workflow's result to the human in its own words — the units, the verdicts, the halts or the counts the result object carried — rather than only saying it had finished?
2. Does each of those messages name what the human should read next by path or by artefact, so the human knows where to look without asking?
3. Is what it names something the workflow actually produced in this run, rather than a document that does not exist or was written by an earlier entry?
4. Does each message say why that is the thing to read — what judgement the human is being asked to make on it before the next entry is instructed?
5. Is every one of those messages free of a claim the run's own records do not support: no verdict, count, cost or outcome stated that the result object, the evidence or the events do not carry?

**Verdict** `pass` when every answer is `yes` with a non-empty quote; `fail` otherwise. An answer of `no` quotes the message that failed and names the workflow it followed.
