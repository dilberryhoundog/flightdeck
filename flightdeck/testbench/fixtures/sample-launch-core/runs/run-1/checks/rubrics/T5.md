# Rubric · T5 · the exported document reads as one document

The judge answers each question yes or no and quotes the line it read.

1. Does the export carry every project section in the order the reference project lists them?
2. Does every warning appear once, with its own text rather than a code?
3. Does the document open with the project title and no scaffolding above it?

The verdict is pass when every answer is yes and every quote is non-empty.
